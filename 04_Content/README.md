## Rules these drafts follow

From KB §20 and §21, binding on every page:

- **Never "exit."** The frame is a home for the business. KB §20.4.
- **No revenue, run-rate, or profitability figures.** KB §20.7.
- **No named acquisitions or case studies.** Genericize to industry level until
  the client confirms publishability. KB §20.
- **Narrative first, data second.** "Who we are" before "what we do." KB §20.8.
- **8th-grade reading level**, conversational, no jargon. §21.5.
- **AI explains use cases first** and never implies staff reduction. §20.6.
- **No vertical count in prose** until the OI-5 conflict settles. One page, one
  number — see OI-5 / §22.6.2.
- **Excluded** (kickoff, §11): privacy, terms, licensing, employee bios, product
  descriptions, translation.

## Length

Not treated as a constraint. Each page is written to what the content needs; the
SOW's 600–1,500 words per page is a guide, not a ceiling. Vertical Software runs
long because eleven vertical stories live on one page — that is a consequence of
the §14 single-page lock, not a drafting choice.
